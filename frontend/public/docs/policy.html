Политика обработки персональных данных C3AG

Версия 2026-08-01-c3ag-web. Действует с 1 августа 2026 года.

Эта страница описывает, какие данные посетитель может передать через сайт C3AG и чат Clio, и как они используются для ответа на заявку по видеопродакшену, сайту, AI-интеграциям или смежному проекту.

Какие данные обрабатываются

  • текст сообщения и история переписки в чате;
  • страница сайта, выбранное направление, технические параметры браузера и UTM/referrer;
  • имя, телефон, email или Telegram, если посетитель сам их указал;
  • версия согласия, время, источник и технический идентификатор сессии.

Цель обработки

Данные используются только для обработки обращения: понять задачу, подготовить ответ, смету или бриф, передать заявку команде и продолжить коммуникацию по выбранному посетителем каналу.

Yandex ID и голосовые функции

Yandex ID является опциональным. При включении OAuth сайт запрашивает только минимальные разрешённые поля, например имя и email, и не получает телефон автоматически. Голосовые функции работают только по HTTPS и передают аудио на серверную обработку SpeechKit после явного нажатия на кнопку микрофона.

Коммерческие предложения

Email используется для коммерческого предложения только при отдельном согласии посетителя или когда это необходимо для ответа на конкретную заявку.

Передача данных

Команде передаётся минимальный набор данных, нужный для ответа. OAuth-токены, служебные ключи и лишние персональные данные не передаются в Telegram, LLM-маршрутизаторы, бронирование или рекламные системы без отдельного основания.

Сроки и права

Данные хранятся столько, сколько необходимо для обработки обращения, аудита согласий и выполнения законных требований. Посетитель может запросить доступ, уточнение, удаление данных или отзыв согласия по email: michael.poedinenko.mxr@gmail.com.
