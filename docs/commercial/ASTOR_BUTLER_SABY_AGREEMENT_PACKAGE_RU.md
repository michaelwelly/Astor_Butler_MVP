# Пакет документов Astor Butler / Saby

Статус: черновик для внутреннего согласования, подготовки PDF и проверки юристом. Документы не отправлены внешним получателям.

Дата подготовки: 2026-08-02

## Назначение пакета

Пакет оформляет клиентский запуск Astor Butler для ресторана/площадки с будущей интеграцией с Saby. Он сделан по структуре договорного пакета, который пользователь отметил как удачный: основной договор + приложения, каждое приложение закрывает отдельный предмет согласования.

В этом пакете не фиксируются неподтвержденные цены, реквизиты, SLA, доступы или vendor endpoints. Все такие места оставлены как переменные.

## Состав

1. `ASTOR_BUTLER_SABY_SERVICE_AGREEMENT_DRAFT_RU.md`
   Основной договор оказания услуг: предмет, состав услуг, приемка, поддержка, данные, конфиденциальность, IP, ответственность и ограничения.

2. `ASTOR_BUTLER_SABY_ANNEX_1_TZ_RU.md`
   Приложение N 1: техническое задание на Astor Butler для ресторана/площадки.

3. `ASTOR_BUTLER_SABY_ANNEX_2_API_WORKFLOW_RU.md`
   Приложение N 2: API-интеграция Saby и workflow подтверждения бронирований.

4. `ASTOR_BUTLER_SABY_ANNEX_3_DATA_CONSENT_RU.md`
   Приложение N 3: данные, согласия, обработка персональных данных и границы передачи в Telegram/AI/Saby.

5. `ASTOR_BUTLER_SABY_ANNEX_4_MILESTONES_ACCEPTANCE_RU.md`
   Приложение N 4: этапы проекта, результаты, критерии приемки и открытые вопросы.

## Проверенные источники по Saby

- `https://saby.ru/` - официальный сайт Saby; бренд указывается как Saby, ранее СБИС/sbis.
- `https://saby.ru/presto` - Saby Presto как продукт для автоматизации ресторанов, кафе, баров, кофеен и столовых.
- `https://saby.ru/help/presto` - официальная справка по Saby Presto и вариантам Presto Front/Offline/Android.

## Что нужно заполнить перед отправкой клиенту

- юридическое имя, ИНН/ОГРН/ОГРНИП, адреса, банковские реквизиты и подписанты сторон;
- конкретный ресторан/площадка, бренд в интерфейсе и каналы запуска;
- коммерческая модель: стоимость запуска, сопровождение, НДС/без НДС, порядок оплаты;
- SLA/окна поддержки и ответственные лица Заказчика;
- финальная политика обработки персональных данных и согласий;
- правовой статус Исполнителя как оператора/обработчика персональных данных;
- кто владеет Yandex Cloud, Telegram bot, доменом, Saby аккаунтом и API-доступами;
- фактический Saby API contract, credentials, environment, rate limits and representative guidance;
- условия использования AI, SpeechKit, Telegram и внешних провайдеров;
- порядок передачи исходников, конфигурации, документации и результатов работ.

## Send-ready summary

Astor Butler предлагается как управляемый Telegram/AI/FSM-ассистент для ресторана: он собирает запрос гостя, сохраняет историю и согласия, помогает подобрать сценарий бронирования, передает заявку сотруднику и, после подтвержденной интеграции, синхронизирует статус с Saby. Окончательные бронирования, переносы, отмены и спорные действия остаются confirmation-gated и требуют подтверждения уполномоченного сотрудника или явно согласованного внешнего workflow.
