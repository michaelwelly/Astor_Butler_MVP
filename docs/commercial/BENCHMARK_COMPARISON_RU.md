# Сравнение Astor Butler с простым ботом и enterprise AI

> Это коммерческая рамка сравнения. Числа по времени и токенам являются оценочными и должны быть подтверждены отдельным прогоном.

## Сравниваемые варианты

1. Простой Telegram-бот за 5 000 рублей.
2. Astor Butler MVP.
3. Enterprise AI-платформа уровня “миллионы рублей”, включая большие провайдерские решения.

## Главная разница

Простой бот отвечает кнопками.
Enterprise AI отвечает моделью.
Astor Butler управляет гостевым сценарием.

## Таблица

| Критерий | Бот за 5 000 руб. | Astor Butler MVP | Enterprise AI |
| --- | --- | --- | --- |
| Telegram entry | Да | Да | Обычно через интеграцию |
| FSM-сценарии | Минимальные | Да, source of truth | Не всегда |
| Consent/contact | Часто вручную | Да | Да, но дорого |
| Бронирование | Форма/заявка | Controlled flow + hostess context | Требует интеграции |
| Память предпочтений | Нет | Preference Map | Да, но зависит от DMP/CRM |
| Staff/admin/system chats | Нет | Да | Через отдельные панели |
| Event trail | Нет | PostgreSQL/Kafka/outbox | Да |
| AI boundary | Нет | AI outside business authority | Часто размыта |
| Медиа/меню | Статичные ссылки | PostgreSQL + MinIO catalog | Да |
| Draft confirmations | Нет | Merch/Tip/Donation/Auction | Настраивается |
| Стоимость запуска | Низкая | Средняя | Высокая |
| Скорость адаптации под ресторан | Быстро, но поверхностно | Быстро при наличии контента | Долго |
| Риск “бот сказал лишнее” | Средний | Низкий из-за FSM | Зависит от guardrails |

## Оценка времени повторения проекта

Чтобы повторить Astor Butler с нуля, нужно воспроизвести:

- Telegram transport;
- FSM runtime;
- Redis hot state;
- PostgreSQL durable facts;
- Kafka/outbox trail;
- media pipeline;
- preference memory;
- booking domain;
- staff/admin/system projection;
- AI gateway;
- docs, tests and operational rules.

Оценка для одного сильного инженера с AI-помощником:

```text
6-10 недель до сопоставимого MVP
```

Оценка для команды без накопленного контекста:

```text
2-4 месяца до устойчивого MVP
```

## Оценка токенов для AI-повторения

Для повторения текущего уровня без готовой базы знаний потребуются:

```text
1.5M-4M токенов проектирования, кода, ревью, тестов и документации
```

Если есть текущий репозиторий, graphify и Notion knowledge base:

```text
300k-900k токенов на перенос/адаптацию под новый ресторан
```

## Вывод

Astor Butler не конкурирует с “ботом за 5 тысяч” по цене кнопки.
Он конкурирует по цене потерянного гостя, потерянной брони и потерянного контекста.

С enterprise AI он конкурирует не размером модели, а тем, что ресторану нужен управляемый сценарий, а не свободная генерация.
